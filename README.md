# Dementia Risk Prediction  Indonesia (DEMPRED-ID)

**Development and Validation of a Multi-Domain Machine Learning Model for Dementia Risk Prediction and Cognitive Decline in Older Adults: A Cross-Sectional Study in Two Hospitals in Indonesia**

Principal Investigator: Desy Nuryunarsih, DDS, MPH, PhD  Faculty of Medical Sciences, Population Health Sciences Institute, Newcastle University, UK

Status: 🚧 Protocol / pre-data-collection stage

## Overview

This repository contains the full research protocol, data collection instruments, sample size justification, and analysis pipeline for a cross-sectional, two-hospital study developing an interpretable machine learning framework for dementia risk profiling in Indonesian clinical populations.

The project directly extends the PI's prior published methodology for interpretable, multi-domain tree-based machine learning in cardiovascular risk prediction:

- Nuryunarsih et al. (2023). *Predicting changes in systolic and diastolic blood pressure of hypertensive patients in Indonesia using machine learning.* Current Hypertension Reports, 25(11), 377–383.
- Nuryunarsih et al. (2024). *Utilizing an apriori algorithm to examine attributes associated with hypertension and hypertension cardiovascular patients in Pakistan.* Journal of Medical Artificial Intelligence, 7, 34.
- Nuryunarsih et al. (2025). *Predicting systolic and diastolic blood pressure response using machine learning: A 96-feature analysis in hypertensive patients with comorbidities.* Journal of Current Science and Technology, 15(4), Article 140.

...and addresses the evidence gap identified in:

- Brain, Kafadar, Errington, et al. (2024). *What's new in dementia risk prediction modelling? An updated systematic review.* Dementia and Geriatric Cognitive Disorders Extra, 14, 49–74.

## Study aims (single cross-sectional data-collection wave)

| Aim | Question | Method | Outcome instrument |
|---|---|---|---|
| **1** | Can current cognitive impairment status be predicted from multi-domain risk factors? | Decision Tree / Random Forest / XGBoost classification | MMSE / MoCA (Indonesian-validated) |
| **2** | Which attribute combinations co-occur most strongly with impairment? | Apriori / market-basket association rule mining | Full questionnaire item set |
| **3** | What predicts retrospective 10-year cognitive decline? | Regression / tree-based modelling of informant-rated decline | IQCODE (informant-rated) |

## Reproducing the sample size calculation

No patient data is required to reproduce the power/sample-size justification  it is a Monte Carlo simulation based on assumed prevalence and target discrimination:

```bash
pip install -r requirements.txt
python scripts/00_sample_size_calculation.py
```

This reproduces the Riley et al. (2020) three-criterion sample size table reported in `docs/sample_size_calculation.md` and the study protocol (n ≈ 1,330 for a 30-predictor model targeting C-statistic = 0.80 at 20% prevalence; n ≈ 892 for a 20-predictor consolidated model).

## Data availability

Patient-level data are not included in this repository and will not be made public in raw form due to ethical and privacy constraints. A de-identified analysis dataset and full analysis code will be released alongside the resulting publication(s), consistent with the TRIPOD reporting commitment in `docs/PROTOCOL.md`.

## Ethics

Ethical approval will be obtained from the relevant Indonesian hospital/university ethics committee(s) prior to any data collection (see `docs/PROTOCOL.md`, Section 4.9). This repository currently contains protocol and simulation materials only.
